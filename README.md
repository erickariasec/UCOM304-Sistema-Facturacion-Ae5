# Sistema de Facturación Centralizado - Modelos UML

Repositorio de artefactos UML (PlantUML) para la actividad **Ae5: Paquete de modelos UML con justificación y trazabilidad**.
Asignatura: Ingeniería de Software I (UCOM304) - Universidad Espíritu Santo.

## Contenido del Repositorio
* `diagrama_clases_facturacion.puml`: Código fuente del modelo estructural (Patrón MVC).
* `secuencia_CU03_registrar_venta.puml`: Código del flujo dinámico principal de facturación, cálculo e inventario.
* `secuencia_CU04_autorizar_descuento.puml`: Código del flujo dinámico alternativo para autorización de excepciones comerciales.
* Documento final de entrega con la justificación de relaciones, consistencia, y matriz de trazabilidad.
